# PixelShift 4.7

Conversor de imagens com interface modular em CustomTkinter.

## Execução

```bash
pip install -r requirements.txt
python main.py
```

## Estrutura

- `main.py`: inicialização
- `app.py`: interface e fluxo
- `theme.py`: temas
- `config.py`: configurações
- `core/converter.py`: conversão
- `ui/file_row.py`: item da fila
- `ui/elevated_button.py`: botão com profundidade
- `assets/PixelShift.ico`: ícone
