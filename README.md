# PixelShift 4.5

Aplicativo desktop para conversão de imagens em lote.

## Estrutura

- `main.py`: inicialização.
- `app.py`: janela e fluxo da interface.
- `theme.py`: temas e cores.
- `config.py`: constantes.
- `core/converter.py`: conversão.
- `ui/file_row.py`: itens da fila.
- `ui/elevated_button.py`: botões com profundidade visual.
- `assets/PixelShift.ico`: ícone.

## Execução

```bash
pip install -r requirements.txt
python main.py
```
